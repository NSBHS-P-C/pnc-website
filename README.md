# NSBHS P&C website

Plain static website (HTML + CSS, no build step). Suitable for Azure Static Web Apps.

- `index.html` – Home
- `about.html`, `canteen.html`, `uniform-shop.html`, `falcon-sports-club.html`,
  `events-fundraising.html`, `get-involved.html`, `documents.html`, `contact.html`
- `assets/css/site.css` – shared styles (navy #232844, blue #35457a, light #e6e9f7, gold #d4b56a)
- `assets/img/` – P&C round logo, favicon, home banner
